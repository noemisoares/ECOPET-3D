# ECOPET-3D
## Sobre o projeto

O ECOPET 3D é um projeto que propõe o desenvolvimento de um equipamento capaz de transformar garrafas PET descartadas em filamento para impressão 3D, incentivando o reaproveitamento de resíduos plásticos e o acesso a materiais de fabricação digital de baixo custo.

O equipamento está sendo planejado para realizar quatro etapas principais: corte da garrafa em um filete, aquecimento e deformação do material, tração e enrolamento do filamento.

## Objetivo do repositório

Este repositório tem como objetivo centralizar a documentação técnica, os arquivos de fabricação das peças e os futuros códigos computacionais do ECOPET 3D. Sua organização busca facilitar a continuidade do desenvolvimento e permitir que outras pessoas compreendam os materiais, os procedimentos e as tecnologias necessárias para reproduzir o projeto.

## Estado atual do projeto

O projeto encontra-se em desenvolvimento. Algumas peças físicas já foram fabricadas por impressão 3D, utilizando as impressoras Bambu Lab P2S e Anet A6, com os programas Bambu Studio e Ultimaker Cura.

A montagem completa do equipamento, a integração dos componentes eletrônicos e o desenvolvimento do firmware ainda são etapas pendentes.

## Estrutura prevista

- `docs/`: documentação técnica, arquitetura e instruções de montagem.
- `hardware/`: fotografias, modelos tridimensionais e arquivos de fabricação das peças.
- `firmware/`: código embarcado previsto para o controle do equipamento.
- `tests/`: procedimentos e resultados dos testes realizados.

As pastas e os arquivos serão ampliados conforme o desenvolvimento avançar. Os componentes e as funcionalidades ainda não implementados são apresentados como propostas, não como recursos já disponíveis.

## Tecnologias e ferramentas

- Impressão 3D: Bambu Lab P2S e Anet A6.
- Preparação dos modelos: Bambu Studio e Ultimaker Cura.
- Formatos de fabricação: STL e G-code.
- Controle embarcado previsto: Arduino Nano e componentes eletrônicos compatíveis, sujeitos à validação durante a montagem.

## Próximas etapas
